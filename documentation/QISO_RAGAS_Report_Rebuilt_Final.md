# تقرير تقييم نظام QISO باستخدام RAGAS

## 1. الهدف

يوثق هذا التقرير التقييم النهائي لنظام **QISO RAG** باستخدام إطار **RAGAS**، ويعتمد مباشرة على ملف النتائج الخام **`ragas_results_final.csv`**. يركز التقييم على وفاء الإجابة بالسياق، وارتباط الإجابة بالسؤال، ودقة السياقات المسترجعة، وصلتها بالسؤال.

## 2. بيانات التقييم وإعداداته

| العنصر | القيمة |
|---|---|
| عدد أسئلة التقييم | **30 سؤالًا** |
| اللغة | **العربية: 30/30**؛ توجد مصطلحات لاتينية/إنجليزية داخل 4 أسئلة تقنية، لكن صياغة الأسئلة عربية |
| الأسئلة المكتملة | **30/30** |
| أخطاء التشغيل المسجلة | **0** |
| Retrieved Contexts | **5 مقاطع لكل سؤال** |
| Reference Answers | ملف CSV لا يحتوي عمود `reference_answer` أو `ground_truth`; التقييم النهائي لا يعتمد على Reference Answer |
| `reference_count` في CSV | 28 سؤالًا بقيمة 1، و2 سؤالين بقيمة 2؛ هذا الحقل لا يُعامل كـ Reference Answer |

> **ملاحظة توثيقية:** عدد الأسئلة، اللغة، عدد الـcontexts، الحالات والأخطاء والنتائج الإحصائية أدناه مأخوذة مباشرة من CSV النهائي. أما إصدار RAGAS ونماذج التقييم فهي من إعداد التقييم المستخدم في المشروع وليست حقولًا مخزنة داخل CSV.

## 3. المقاييس والنتائج

| المقياس | اسم Metric المستخدم | المتوسط | الأدنى | الأعلى |
|---|---|---:|---:|---:|
| Faithfulness | `Faithfulness` | **0.9236** | 0.7143 | 1.0000 |
| Answer Relevancy | `AnswerRelevancy` | **0.9547** | 0.7459 | 1.0000 |
| Context Precision | `ContextPrecisionWithoutReference` | **0.9358** | 0.7000 | 1.0000 |
| Context Relevance | `ContextRelevance` | **1.0000** | 1.0000 | 1.0000 |
| Overall Average* | متوسط حسابي | **0.9535** | — | — |

\* **Overall Average ليس Metric مستقلًا في RAGAS.** وهو متوسط حسابي للمقاييس الأربعة فقط:

`(0.9236 + 0.9547 + 0.9358 + 1.0000) / 4 = 0.9535`

## 4. تفسير النتائج

- **Faithfulness = 0.9236:** يشير إلى أن أغلب الادعاءات في الإجابات مدعومة بالسياقات المقدمة، مع وجود حالات محدودة تحتاج تشددًا أكبر في الالتزام بالأدلة.
- **Answer Relevancy = 0.9547:** يعكس بقاء الإجابات مرتبطة مباشرة بأسئلة المستخدم في غالبية الحالات.
- **Context Precision = 0.9358:** يدل على جودة مرتفعة في ترتيب وفائدة المقاطع المسترجعة دون استخدام Reference Answer.
- **Context Relevance = 1.0000:** حصلت جميع حالات التقييم **30/30** على 1.0000 في هذا المقياس. هذا يعني أن السياقات المقيمة اعتُبرت ذات صلة بالسؤال وفق المقياس المستخدم، لكنه **لا يساوي Context Recall** ولا يثبت أن النظام استرجع كل المعلومات ذات الصلة الموجودة في corpus.

## 5. قراءة تفصيلية من النتائج الخام

- **27/30** سؤالًا حقق متوسطًا كليًا يساوي أو يتجاوز 0.90.
- **16/30** حالة حققت Faithfulness = 1.0000.
- **17/30** حالة حققت Context Precision = 1.0000.
- أقل متوسط إجمالي ظهر في **Q23 = 0.8462** للسؤال: *لماذا ينبغي ألا يكون المدقق مشاركا في النشاط الذي يفحصه؟*.
- أدنى Faithfulness ظهر في **Q24 = 0.7143**.
- أدنى Answer Relevancy ظهر في **Q23 = 0.7459**.
- أدنى Context Precision كان **0.7000** في **Q01** و**Q03**.
- جميع الأسئلة الثلاثين تحمل حالة **PASS** ولا توجد أخطاء مسجلة في عمود `error`.

## 6. اكتمال التقييم وحدوده

اكتمال **30/30** سؤالًا يعني أن التقرير يغطي مجموعة الاختبار كاملة دون فقد نتائج بسبب أخطاء التنفيذ. ومع ذلك، فإن قوة الاستنتاج لا تعتمد على اكتمال التشغيل وحده؛ بل تعتمد كذلك على **جودة الأسئلة، تنوعها، وتمثيلها لحالات الاستخدام الفعلية**. مجموعة الاختبار الحالية عربية بالكامل، لذلك لا يمكن استخدام هذا التشغيل وحده لإثبات جودة الأداء على الأسئلة الإنجليزية. كذلك، لعدم وجود Reference Answers صريحة، لم يُقَس **Context Recall المرجعي** في هذا التشغيل.
